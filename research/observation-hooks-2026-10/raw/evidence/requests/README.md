# Hosted critic requests

Requested profile and exact prompt for each of the four hosted critics
(`gpt-6.1-sol`, reasoning `xhigh`, `serviceTier: fast`, read-only reviewer role,
`networkAccess: restricted`). Host names, registry and auth-pool paths, account
slots and the operator start script were removed for this public repository;
the unredacted operator records remain with the operator. Each job received the
same input packet; `../critic-input-hashes.json` records the hashes of that
packet, most of which is not part of this archive.
